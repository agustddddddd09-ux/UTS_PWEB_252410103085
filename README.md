# Taskly - Laravel 13

Taskly merupakan aplikasi berbasis web yang dibuat menggunakan Laravel 13 sebagai proyek praktikum Pemrograman Web.

## Deskripsi
Aplikasi Taskly memiliki beberapa halaman yang digunakan untuk menampilkan dan mengelola informasi melalui antarmuka web.

## Fitur
- Halaman Login
- Dashboard
- Halaman Profile
- Halaman Pengelolaan

## Teknologi yang Digunakan
- Laravel 13
- PHP
- HTML
- CSS
- JavaScript
- Blade Template Engine

## Instalasi
1. Clone repository ini.
2. Jalankan `composer install`.
3. Salin `.env.example` menjadi `.env`.
4. Jalankan `php artisan key:generate`.
5. Jalankan `php artisan serve`.
